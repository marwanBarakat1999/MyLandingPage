01 — Operations toolkit · Government contact center

No in-house tooling, strict security rules. So I built the toolkit.

About 20 Windows servers plus CUCM, Finesse, CUIC and VVB, and every health check or log hunt was done by hand, server by server. I designed a set of web tools on one central server, fed by a small agent on each machine: health monitoring, log collection that traces a single call, and IVR analytics.

02 — WFM forecast & scheduler

They asked for a forecast. The data showed a staffing problem.

Operations wanted call-volume predictions and a way to stop schedules that broke the rules from reaching the WFM system. In the numbers I saw service level running far below its target, so the request grew into a tool: Erlang C forecasts per shift and skill queue, and a bilingual scheduler that checks every rule before export.
